## Hi there 👋

I like to figure out why and how with anything I come across. Even with things that already work just fine, I find the need to create a Deeper understanding of... whatever it is that I'm focused on. So I tinker. I ask why is it done this way and not this way? Why doesnt it have the ability to do this? etc... Pretty much all the things I've built, were built with a specific use case in mind.. To solve a problem no one else cared to. My ideology behind this is that I'm hoping that there are others that think the same things I do, and appreciate my work... However, at the end of the day, I like learning, taking on challenges, and building new things; this is what I'd do in a void or with an audience, but it always helps me keep building when theres at least one person that's appreciated something I've built. So enjoy! Ask questions! Request features! I'm here to help.
